# Changelog

## 3.1.2.5.5.6 — 2026-10 (versionCode 113)

A complete redesign of the original runner into **Hopinet**.

* New identity: courier animals (7 heroes), new villain Captain Krab, new bright palette and UI.
* Fully 3D world: sea, scenery and sky all around, never a black background.
* New movement: swim, dive, jump flips, broken bridges; swim sections in every world.
* Rideable vehicles found on the road: car, speed boat, ship, plane (3 altitude lanes, rings, storms).
* Power-ups: Magnet, Gold Doubler, Jet Pack, **Bomb Magnet**, **Helmet** (muffles the audio while worn).
* 36 campaign stages on a real offline world map (with optional "My location" pin), 3 stars each.
* Luxury home per world: 5 build stages + 10 luxury items that boost gold.
* Big green **Run again** button after a fall/crash and on the results screen.
* New energetic procedural music per world, engine and ambient sounds.
* Two Android editions: `play` (real Google Play Billing, `com.elevo.hopinet`) and `free` (`com.elevo.hopinet.free`, no billing).
* GitHub Actions: CI, release (signed APK/AAB), Pages (web build + privacy policy).
* Web builds: multi-file PWA (installable, offline) and a single self-contained HTML file.
